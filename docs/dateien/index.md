# Datei-Export

Der Datei-Export legt Dokumente aus ecoDMS regelbasiert in lokalen Ordnern ab –
mit frei wählbarem Zielordner, eigenem Dateinamen-Schema und Rückschreibung nach ecoDMS.

Typische Einsatzzwecke:

- Übergabe an ERP / Fremdsysteme 
- Belegablage je Jahr, Monat oder Dokumentenart
- Spiegelung der ecoDMS-Ordnerstruktur auf ein Netzlaufwerk
- Übergabe von Dokumenten an Dritte, die keinen ecoDMS-Zugang haben

Sie können beliebig viele Definitionen anlegen, einzeln oder als Gesamtlauf ausführen und
über die Aufgabenplanung automatisieren.
