# Grundeinrichtung

Dieser Abschnitt führt Sie durch die Einrichtung des arkivado CONNECTOR bis zur
ersten funktionsfähigen Verbindung.

!!! note ""
    Der arkivado Connector verbindet sich mit ecoDMS mit der sogenannten API Schnittstelle.
    Deshalb ist es notwendig die API in den ecoDMS Einstellungen freizuschalten ( [Konfiguration des ecoDMS API Zugriffs](<002 Vorbereitung ecoDMS.md>) ). Da Dokumente/Belege zu Datev Unternehmen Online (DUO) übertragen werden verbraucht ecoDMS API-Punkte. Diese sind nur in der ***ecoDMS ONE Lizenz*** enthalten. Mit der Business bzw. Privat Edition können keine Dokumente exportiert bzw. übertragen werden.
